# Frontend engineering
Use React + TypeScript + Vite, React Router, TanStack Query, React Hook Form and Zod. Build accessible responsive components; mobile-first. Keep server state in Query, local UI state local. Never put secrets/service-role keys in browser code. API calls use a centralized typed client and handle sleeping backend/cold-start states. Preserve PWA installability and do not claim offline writes unless sync/conflict behavior is implemented. Add component and flow tests.
