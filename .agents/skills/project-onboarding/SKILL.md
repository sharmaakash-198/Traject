# Project onboarding
1. Read root `AGENTS.md`, `docs/STATUS.md`, `docs/PRD.md`, `docs/ARCHITECTURE.md`, `docs/DECISIONS.md`.
2. Identify current phase and the smallest next task. Do not start later-phase modules early.
3. Inspect existing patterns before creating new ones. Ask before changing a final decision.
4. Implement incrementally; run relevant checks; update STATUS and docs.
5. Report changed files, commands/results, limitations and next task.
