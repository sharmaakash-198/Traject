# Resume and LaTeX workflow
The user's existing Overleaf project is the source template; do not redesign or replace it without permission. Inspect all `.tex`, `.cls`, `.sty`, fonts, images and build instructions. Tailor only claims supported by master resume/evidence. Never invent metrics, skills, employers, dates or achievements. Maintain one-page output and verify PDF page count, text extraction and layout. Keep source and PDF versions immutable after approval; record checksum, job association, prompt/model metadata and claim evidence. Test Tectonic/XeLaTeX against the actual uploaded project before selecting a cloud strategy.
