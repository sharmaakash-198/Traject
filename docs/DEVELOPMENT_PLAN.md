# Development plan

1. **Phase 0 — Foundation:** validate local toolchain, package graph, local Supabase, Prisma, CI, LaTeX compiler and Gmail OAuth feasibility.
2. **Phase 1 — Core CRM:** companies, jobs, JD versions, applications, status history, timeline, duplicate detection, dashboard.
3. **Phase 2 — Resume intelligence:** master resume, evidence-backed tailoring, LaTeX compiler adapter, immutable versions and approval.
4. **Phase 3 — Recruiters:** profile records, email provenance and job associations.
5. **Phase 4 — Email automation:** structured drafts, exact-content approval, Gmail send and idempotency.
6. **Phase 5 — Gmail sync and reminders:** sent/reply history, thread association, on-demand sync and follow-ups.
7. **Phase 6 — Recruitment lifecycle:** interviews, rounds, assessments, offers, outcomes and analytics.
8. **Phase 7 — AI and MCP:** assistant, reports, permissioned MCP tools and audit trail.
9. **Phase 8 — Cloud deployment:** Cloudflare Pages, Render Free, Supabase production, PWA/mobile acceptance, backup/restore.

Do not start a later phase until the previous phase's exit criteria are met and recorded in STATUS.
